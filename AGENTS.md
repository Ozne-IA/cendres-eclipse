# Mémoire de Cendres de l’Éclipse

1. Vérifier que `origin` pointe vers `Ozne-IA/cendres-eclipse`. Partir de `origin/main` dans ce dépôt ou un worktree du même dépôt.
2. Lire [Point de reprise](docs/obsidian/Point%20de%20reprise.md), puis [Accueil](docs/obsidian/Accueil.md). Ouvrir ensuite les notes utiles à la tâche parmi Architecture, Décisions et Validation.
3. Pour explorer le code, utiliser le [skill Graphify](.agents/skills/graphify/SKILL.md) et vérifier les relations utiles dans les sources. Pour modifier le coffre, suivre le [skill Obsidian Markdown](.agents/skills/obsidian-markdown/SKILL.md). Lors d’une délégation, préciser le périmètre et les notes utiles.
4. En fin de tâche, mettre à jour le Point de reprise avec l’état vérifiable, les contrôles effectués ou restants et la prochaine action. Consigner dans Décisions les choix durables et dans Validation les contrôles réutilisables.

Garder la mémoire partagée dans `docs/obsidian/`. Exclure de Git les exports Graphify, les réglages Obsidian, les secrets, les sauvegardes et les notes personnelles. Travailler depuis le dépôt canonique sans créer de clone supplémentaire.
