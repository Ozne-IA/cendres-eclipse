# Cinematic Assets v2

These four biome backgrounds ship with the cinematic art style.

## Required files

```
biome_catacombes_v2.jpg
biome_viaduc_v2.jpg
biome_fleche_v2.jpg
biome_sanctuaire_v2.jpg
```

The cinematic setting in Graphismes & HUD selects these images.
If any file is missing, the game silently falls back to the classic backgrounds.

## Optional (future)

```
character/
  pilgrim_of_ash_*.png   ← isolated sprites / skins
weapons/
  weapon_*.png           ← improved weapon stamps
```

The system is designed to never break the game.
